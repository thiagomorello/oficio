{{ .Values.office.appName }} ({{ .Chart.Name }} chart {{ .Chart.Version }}, app {{ default .Chart.AppVersion .Values.image.tag }}) is being rolled out in namespace {{ .Release.Namespace }}.

1. Wait for the app:

   kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "oficio.fullname" . }}
   kubectl -n {{ .Release.Namespace }} logs deployment/{{ include "oficio.fullname" . }} -f

{{- if .Values.ingress.enabled }}

2. Point the DNS record {{ .Values.ingress.host }} at your Ingress controller, then check:

   curl -fsS {{ $url }}/api/health      # {"ok":true,"db":"ok",...,"livekit":{{ ternary "true" "false" (or .Values.livekit.enabled (ne .Values.livekit.external.url "")) }}}
{{- else }}

2. No Ingress was created (ingress.enabled=false). For a quick look from your machine:

   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "oficio.fullname" . }} 4747:{{ .Values.service.port }}
   curl -fsS http://127.0.0.1:4747/api/health

   Browsers need HTTPS for microphone and camera, so expose the office through an Ingress (or any TLS proxy) before
   inviting people. The session cookie is Secure (office.cookieSecure=true).
{{- end }}

3. Create the first administrator (prints a temporary password ONCE; it must be changed at first login):

   kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "oficio.fullname" . }} -- \
     node dist/server/cli.js create-admin --email you@example.com --name "Your Name"

{{- if .Values.livekit.enabled }}

4. Audio/video: the bundled LiveKit is at {{ include "oficio.livekit.publicUrl" . }} (signaling) and announces media on
   {{ .Values.livekit.rtc.tcpPort }}/tcp and {{ .Values.livekit.rtc.udpPort }}/udp.
{{- if .Values.livekit.hostNetwork }}
   hostNetwork=true: open those two ports on the firewall / security group of the node that runs the LiveKit Pod.
   The node's public IP is announced to browsers ({{ ternary "discovered via STUN" (printf "pinned to %s" .Values.livekit.rtc.nodeIp) (empty .Values.livekit.rtc.nodeIp) }}).
{{- else }}
   hostNetwork=false: the Service {{ include "oficio.livekit.fullname" . }}-rtc ({{ .Values.livekit.service.type }}) forwards those ports 1:1.
   {{- if eq .Values.livekit.service.type "NodePort" }} The ports must be inside the cluster's node-port range (default 30000-32767).{{- end }}
   {{- if eq .Values.livekit.service.type "LoadBalancer" }} Set livekit.rtc.nodeIp to the load balancer's IP once it is assigned.{{- end }}
{{- end }}
{{- if .Values.livekit.ingress.enabled }}
   DNS for {{ .Values.livekit.ingress.host }} must be a plain A/AAAA record (no CDN proxy) pointing at the Ingress controller.
{{- end }}
   Test it end to end with two browsers: `livekit: true` in /api/health only means the app can reach the LiveKit API.
{{- else if .Values.livekit.external.url }}

4. Audio/video: using the external LiveKit at {{ .Values.livekit.external.url }}. Make sure LIVEKIT_API_KEY /
   LIVEKIT_API_SECRET in the Secret are the pair of that project; a mismatch shows up as 401 in the browser console.
{{- else }}

4. Audio/video is OFF: livekit.enabled=false and livekit.external.url is empty. Presence and chat work; set one of
   them to enable A/V.
{{- end }}

Things to keep in mind
- Exactly one app replica (strategy Recreate): the office state is in process memory. Scale up, never out.
{{- if .Values.mysql.enabled }}
- The bundled MySQL is a single StatefulSet with a {{ .Values.mysql.persistence.size }} volume. Back it up (mysqldump of
  "{{ .Values.mysql.auth.database }}") and prefer a managed database for production (mysql.enabled=false + mysql.external.*).
{{- end }}
{{- if not .Values.secrets.existingSecret }}
- Generated secrets live in Secret/{{ include "oficio.secretName" . }} and are reused on upgrades. Back the Secret up:
  losing OFFICE_JWT_SECRET signs everyone out, losing the MySQL passwords locks you out of the data.
{{- end }}
- Upgrade: helm upgrade {{ .Release.Name }} <chart> -n {{ .Release.Namespace }} -f your-values.yaml --set image.tag=X.Y.Z
  Migrations are additive and run at boot; rolling back the image tag is safe.
